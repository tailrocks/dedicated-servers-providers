# Non-ECC memory for 128 GB and 256 GB CI hosts

**Checked 20 November 2026, Asia/Saigon.** For the closest one-host AX162 substitute, use **eight 32 GB Kingston KVR32N22D8/32 DDR4-3200 non-ECC UDIMMs** on the original ASUS WRX80E-SAGE SE WIFI. They use all eight memory channels and provide one 256 GB address space. For a lower-cost 128 GB desktop, use one **2×64 GB DDR5** kit in Singapore or two exact 64 GB JEDEC UDIMMs in Malaysia. Malaysia also has a documented 256 GB, 4×64 GB non-ECC DDR5 option. Its dual-channel desktop CPU and lower rated memory clock materially change the performance comparison. ## DDR4, DDR5 and threads competing for memory

Peak payload below is **active channels × 8 bytes × transfer rate**. These theoretical decimal GB/s illustrate why the number of populated channels matters to concurrent compilers. Sustained usable bandwidth, latency and build speed depend on the workload, firmware and module layout. [AMD EPYC 9454P](https://www.amd.com/en/products/processors/server/epyc/4th-generation-9004-and-8004-series/amd-epyc-9454p.html) · [AMD 5995WX](https://www.amd.com/en/support/downloads/drivers.html/processors/ryzen-threadripper-pro/ryzen-threadripper-pro-5000wx-series/amd-ryzen-threadripper-pro-5995wx.html) · [AMD Ryzen 9 9950X3D](https://www.amd.com/en/products/processors/desktops/ryzen/9000-series/amd-ryzen-9-9950x3d.html) · [Intel DIMM-population table](https://edc.intel.com/content/www/us/en/design/products/platforms/details/arrow-lake-s/core-ultra-200s-series-processors-datasheet-volume-1-of-2/processor-sku-support-matrix/)

| Topology | Theoretical payload GB/s | What limits the comparison |
|---|---:|---|
| EPYC 9454P, 12 populated DDR5-4800 channels | 460.8 | CPU maximum. Hetzner's advertised memory capacity does not establish twelve populated channels. A 4-channel example would be 153.6 GB/s at this rate. |
| WRX80, 8 populated DDR4-3200 channels | 204.8 | Applies to both 8×16 and 8×32 when trained at 3200. Four 32 GB modules use four channels and would halve the ceiling to 102.4. |
| Dual-channel desktop, DDR5-5600, 2 DIMMs | 89.6 | AMD's published rating for either rank type at two DIMMs. Intel's four-slot board topology with one ordinary UDIMM per channel is rated 5600. KLEVV's 6000 overclock profile would give 96.0 if attained. |
| Intel dual-channel, DDR5-4400, 4 dual-rank DIMMs | 70.4 | Intel's table differentiates two ranks from single-rank 2DPC (4800). The high-level 7200 maximum uses a different topology/module type. |
| Ryzen dual-channel, DDR5-3600, 4 DIMMs | 57.6 | AMD's rated four-DIMM speed for one or two ranks per DIMM. A board/kit-specific higher EXPO speed is an overclock. |

An additional 128 GB helps when simultaneous Cargo/rustc workers, linkers, containers, Node heaps and the page cache would otherwise exhaust the first 128 GB. A single CPU-bound TypeScript step can see little benefit from more idle RAM. Effective worker capacity depends on the largest job's peak live set plus overlapping jobs, services and filesystem cache. When memory pressure causes swapping, a RAM upgrade can dominate a modest CPU or SSD improvement. No public source times these exact capacity changes on the user's pipeline. [CI stage analysis](ci-cd-performance-analysis.md)

At 128 GB, **2×64 DDR5** leaves two physical sockets free. Moving to 256 GB incurs 2DPC electrical loading and a lower controller rating. Two independently purchased performance kits with the same marketing name do not establish four-DIMM qualification. The four-JEDEC-module Malaysian configuration has exact board and memory-manufacturer support. A 256 GB WRX80 machine already fills all eight sockets. A two-node 128+128 GB pool can run independent memory-heavy jobs but each job still fits within one 128 GB machine.

DDR5's internal on-die ECC corrects faults within each DRAM chip. End-to-end system ECC adds bus-level protection and requires appropriate memory, CPU and board. The named ordinary unbuffered non-ECC modules meet the hardware requirement. Modern TRX50 / WRX90 workstation boards considered here take **ECC registered DIMMs**. Disabling a firmware error-reporting option does not make such a DIMM an ordinary non-ECC UDIMM. The original WRX80's documented support for both classes permits the older eight-channel alternative.
