# Dedicated server comparison

Find a physical server with **AMD EPYC 9454P-class performance or better, at least 128 GB of RAM and at least 2 TB of raw SSD storage**. The rental comparison prefers NVMe and excludes virtual servers and dedicated-vCPU plans.
