# Dedicated Servers Providers

Where to buy dedicated servers with the best price.

Single source of truth: this README table. Sorted by price (cheapest first). PRs welcome.

## How to add / update

1. Add one row per server / promotion.
2. Keep sorted by `Price (USD/mo)` ascending.
3. `Specs` format: `CPU / RAM / Storage / Bandwidth` — e.g. `Ryzen 9 7950X (16c/32t) / 128GB DDR5 / 2x1TB NVMe / 1 Gbps unmetered`.
4. `URL` must be a direct link to that server / promotion, not a homepage.
5. Update `Last checked` when you verify the price.

Template:

```markdown
| Provider | Location | Specs | Price (USD/mo) | URL | Last checked | Notes |
|----------|----------|-------|----------------|-----|--------------|-------|
| Acme Host | Frankfurt, DE | Ryzen 9 7950X / 128GB / 2x1TB NVMe / 1 Gbps | $99 | https://example.com/server/xyz | 2026-11-19 | promo, setup fee waived |
```

## Columns

- **Provider** — company name.
- **Location** — datacenter city / country.
- **Specs** — CPU / RAM / Storage / Bandwidth.
- **Price (USD/mo)** — recurring monthly price in USD, before VAT. Add setup fee to Notes if any.
- **URL** — direct link to that promotion / server config.
- **Last checked** — `YYYY-MM-DD` when price was verified.
- **Notes** — promo code, setup fee, contract term, stock, etc.
